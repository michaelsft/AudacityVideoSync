# Security

Please do not post exploitable security vulnerabilities in a public issue. Use GitHub's private [Report a vulnerability](https://github.com/michaelsft/AudacityVideoSync/security/advisories/new) form. If that form is unavailable, open a public issue containing no vulnerability details and ask the maintainer to establish private contact.

Audacity Video Sync communicates with Audacity through `mod-script-pipe`. Audacity describes this as a developer-oriented external control interface. Users should only enable it on a trusted personal computer and should not expose it in a server or untrusted multi-user environment.

Only the latest public release is supported for security fixes.
